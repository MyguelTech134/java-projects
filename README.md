## Projects

### 1. Shopping List

A small console program where you can add items to a list
and show the list.

- Add an item (name, quantity, price)
- Show all items
- Quit the program

Files:
- `Item.java` – one item (name, quantity, price)
- `Main.java` – the menu

How to run: open the folder in IntelliJ IDEA and run `Main.java`.
